RNDM Chat v23 — REAL RANDOM CHAT

Что изменено:
- Случайный чат снова основная функция RNDM.
- В верхнем меню появился отдельный пункт «🎲 Рандом».
- Реальный matchmaking через Supabase между двумя аккаунтами.
- Рулетка пользователей во время поиска.
- После совпадения автоматически создаётся реальный личный чат.
- Кнопки: Открыть чат / В друзья / Следующий / Стоп.
- Случайный чат также выделен на главной и в списке чатов.

ВАЖНО:
Если v22 уже установлен, в Supabase SQL Editor нужно ОДИН РАЗ выполнить:
supabase_v23_random_chat.sql

Для новой базы можно использовать supabase_FULL_v23.sql.

Проверка:
1) Загрузить все файлы v23 на GitHub Pages.
2) Выполнить SQL upgrade.
3) Открыть random.html на двух устройствах под разными аккаунтами.
4) На обоих нажать «Искать человека».
5) Должно появиться совпадение и один общий чат.
