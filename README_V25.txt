RNDM Chat v25

Главное:
- Рефералы теперь работают через Supabase между разными устройствами.
- Admin Center умеет управлять пользователями и почти всем облачным контентом сайта: чаты, сообщения, каналы, посты, комментарии, Clips, Video, Market, Stories, события, кредиты, квартиры, дружба, уведомления и рефералы.
- Owner/Admin могут редактировать и удалять контент. Moderator может удалять обычный пользовательский контент, но не системные/финансовые сущности.
- Очистка контента пользователя и Owner-only удаление профиля приложения добавлены отдельно.
- Все действия пишутся в admin_audit.

ОБНОВЛЕНИЕ С v24.2:
1) Выполнить supabase_v25_upgrade.sql в Supabase SQL Editor.
2) Загрузить все файлы v25 на GitHub Pages с заменой старых.
3) Выйти/войти в аккаунт, чтобы убрать старый кэш.
4) Проверить cat.html -> реферальная ссылка.
5) Проверить admin.html -> вкладка Контент.

Важно: admin_delete_app_profile удаляет профиль приложения и его публичные данные, но не запись auth.users. Полное удаление Supabase Auth требует серверного Admin API/Edge Function с secret key; secret key нельзя размещать в GitHub Pages.
