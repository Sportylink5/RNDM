RNDM Chat v26 — ALL FEATURES

Supabase проекта Rndm уже обновлён напрямую. Повторно выполнять SQL для текущего проекта не нужно.

Главное в v26:
- Уведомления в приложении + системные уведомления браузера, счётчик непрочитанных.
- Онлайн/last seen, «печатает…» и «записывает голосовое…».
- Звонки 2.0: входящий вызов Принять/Отклонить, история, камера/микрофон, демонстрация экрана.
- Отдельная страница группового WebRTC-звонка до 8 участников.
- Чаты 2.0: закрепление/архив, просмотр архива, поиск, избранные сообщения, пересылка, ответы, свайп вправо для ответа, исчезающие и запланированные сообщения, ✓/✓✓, голосовые.
- Профили 2.0: рамки, цвет, музыка, скрытие last seen, подарки, выбранные Clips.
- Clips 3.0: Для вас / Подписки / Сохранённые / История, тренды, сохранение облачных Clips, витрина профиля, видео-ответ на комментарий, 2× удержанием.
- Биржа 2.0: лимитные заявки, новости с влиянием на цену, дивиденды, график 1д/7д/30д/всё, топ инвесторов.
- Сезон 1 + бесплатная/Premium дорожка и награды.
- Подарки за Stars с редкостью и лимитированными подарками.
- Admin 2.0: объявления, мут, запрет публикаций, режим техработ, биржевые события, существующая модерация/аудит/контент-менеджер.
- Публичные комнаты и групповые голосовые/видео-комнаты через Group Calls.
- PWA: manifest, service worker, установка на телефон/ПК и offline shell.
- Во всех облачных комментариях Channels / Video / Clips показываются аватар, имя, @username и время; имя открывает профиль автора.
- Цензура v25.7 сохранена и работает на старом и новом контенте.
- Защищены привилегированные поля профиля: обычный пользователь не может сам выдать себе Owner/Stars/XP через DevTools.
- Мут/запрет публикаций теперь проверяются сервером.

Важно про push:
Системные уведомления браузера работают, когда сайт/PWA запущен. Полностью серверный Web Push для закрытого приложения требует отдельного безопасного VAPID secret/Edge Function; секрет в статические файлы не добавлялся.
