RNDM Chat v18 — НАСТОЯЩАЯ ПЕРЕПИСКА МЕЖДУ УСТРОЙСТВАМИ

1. Создай бесплатный проект на https://supabase.com/
2. Открой SQL Editor -> New query.
3. Вставь весь файл supabase_schema.sql и нажми Run.
4. Открой Project Settings -> API. Скопируй Project URL и Publishable key (или anon key).
5. Открой файл rndm-cloud.js и замени:
   PASTE_YOUR_SUPABASE_URL_HERE
   PASTE_YOUR_PUBLISHABLE_OR_ANON_KEY_HERE
6. В Authentication -> URL Configuration добавь адрес GitHub Pages в Site URL, например:
   https://sportylink5.github.io/
7. Для простой демонстрации можно в Authentication -> Providers -> Email отключить Confirm email.
   Если подтверждение включено — после регистрации нужно подтвердить письмо.
8. Загрузи ВСЕ файлы из архива в корень GitHub-репозитория.

После этого два разных телефона/браузера смогут создать разные аккаунты и реально переписываться.

Работает через облако:
• регистрация/вход
• профили и аватары
• поиск пользователей
• заявки в друзья / принятие / удаление
• личные чаты
• групповые чаты
• мгновенные сообщения
• фото / видео / файлы до 50 МБ
• индикатор «печатает…»
• онлайн / последний визит
• отметка прочтения
• реакции
• редактирование и удаление своих сообщений

ВАЖНО: Publishable/anon key можно использовать в браузере. НИКОГДА не вставляй service_role key в сайт.
