RNDM Chat v24 MEGA + Admin Center

1. Если у вас уже установлен v23: выполните supabase_v24_upgrade.sql в Supabase SQL Editor.
2. Если база новая: выполните supabase_FULL_v24.sql.
3. Зарегистрируйтесь/войдите в свой RNDM аккаунт.
4. Откройте MAKE_ME_OWNER.sql, замените YOUR_EMAIL@example.com на email ВАШЕГО аккаунта и выполните запрос в SQL Editor.
5. Загрузите все файлы v24 в корень GitHub Pages с заменой старых.
6. После назначения Owner в бургер-меню появится Admin Center.

Новые страницы: admin.html, search.html, stories.html, daily.html, leaderboard.html, events.html, calls.html.
Random 2.0 получил фильтры режима/языка/интересов.
